📡 Сетевой чат (Курсовой проект)
Java

Простой, но мощный многопользовательский консольный чат с возможностью работы по сети. Проект включает серверную часть и клиентские приложения с полным логированием переписки.

🚀 Возможности
Многопользовательский чат - общение между несколькими клиентами

Кроссплатформенность - работает на любой системе с Java

Логирование - все сообщения сохраняются в файлы

Простое управление - интуитивно понятные команды

Гибкие настройки - конфигурация через файл настроек

Требования:
Java 17 или новее

🛠 Настройка
Перед запуском создайте файл settings.txt в корневой директории с номером порта:

8080
🖥 Использование
Сервер
Запускается на указанном порту, ожидает подключений клиентов.
Все сообщения логируются в server.log
Клиент
После запуска:
1. Введите свое имя
2. Начните общение
3. Для выхода введите /exit
   Ваша переписка сохраняется в client_<ваше_имя>.log
